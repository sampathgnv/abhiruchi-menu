# Photographs go here

This folder is empty on purpose. Photos of the sweets belong here, one per item, each named after that
item's `id` from `catalog.json` — for example `bobbatlu.webp`.

See [`../ADDING-IMAGES.md`](../ADDING-IMAGES.md) for the naming rule, the sizes to shoot at, and how to
switch photos on in the app.

Keep this file so the folder still exists in the repository while it is empty; GitHub does not store
folders with nothing in them.
